# D-01 Simulator CLI reports OS-level failures as generic INTERNAL

- Severity: Low
- Component: teecustody-sim (`cli.py`, `_error_line`)
- Violates: FR-3 (stable error codes, API.md section C: exit 2 for validation errors); usability of the CLI
- Found by: QA exploratory, INC-1

## Reproduction
1. `teecustody-sim serve --audience https://a.test/x --image-reference r --image-digest sha256:<64 hex> --state-dir /tmp/s --socket /tmp/an-existing-directory`
2. Also: `teecustody-sim vectors --state-dir /tmp/s --out /` (unwritable directory), and
   `serve ... --issuer-host example.com --allow-non-loopback` (unbindable address).

## Expected
A specific stable validation code (for example `INVALID_PATH`) and exit status 2, as for a regular file or
symlink at the socket path (which already yield `INVALID_PATH`).

## Actual
stderr is `INTERNAL`, exit status 1. The operator cannot distinguish a bug from a bad argument or a permission problem.
No data is leaked and no file is clobbered; the impact is diagnosability only.
