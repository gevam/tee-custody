# D-04 `serve --env` accepts an empty variable name

- Severity: Low
- Component: teecustody-sim `cli.py` (`_env`)
- Violates: SR-3 (validation at the boundary); API.md section C `--env NAME=VALUE`
- Found by: QA exploratory, INC-1

## Reproduction
1. `teecustody-sim serve --audience https://a.test/x --image-reference r --image-digest sha256:<64 hex> --state-dir /tmp/s --socket /tmp/s.sock --env "=x"`

## Expected
`INVALID_ARGUMENT`, exit 2 (as for `--env BADENV`, which is rejected).

## Actual
The simulator starts and records an environment entry with an empty name in the launch configuration, which then
feeds the env digest in every issued token.
