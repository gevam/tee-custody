`pnpm -r test` and `pnpm -r coverage` run for `@teecustody/core`, and the private `tests` workspace package

its frozen signature; the final helpers (`encoding.ts`, `json.ts`, the runtime parts of `attestation/types.ts`)
are fully implemented. Lint enforces the no-DOM/no-fetch/no-eval and single-decoder rules.

  API.md §D [CI-2]); `fetcher.ts` exports `mapFetcher(entries: ReadonlyMap<string, Bytes>): Fetcher` (exact URL →
  `{status: 200, body}`, otherwise rejects `CapabilityError("HTTP_ERROR")`); `jws.ts` exports
  `generateRsaKey(alg: SignatureAlgorithm): Promise<{ privateKey: CryptoKey; jwk: RsaPublicJwk; spki: Bytes }>`
  (2048-bit, e = 65537), `signJws(header: object, claims: object, key: CryptoKey): Promise<string>` (RS256, key
  from `generateRsaKey("RSASSA_PKCS1V15_SHA256")`) and
  `signPayload(alg: SignatureAlgorithm, key: CryptoKey, data: Bytes): Promise<Bytes>`.

Helper semantics (final code, test-first): `base64UrlDecode` rejects `=`, `+`, `/`, whitespace, length ≡ 1
(mod 4) and non-zero unused trailing bits; `base64Decode` requires correct padding and rejects `-`, `_`,
whitespace and non-zero trailing bits; both throw `EncodingError`. `utf8DecodeStrict` uses
`TextDecoder("utf-8", { fatal: true, ignoreBOM: true })`. `getPath` follows own properties only
(`Object.hasOwn`) and returns `undefined` when a segment is absent or a non-object is traversed.
`brandTrustProfile` deep-freezes and registers in a module `WeakSet`; `isBrandedTrustProfile` checks it.

## Acceptance criteria (each becomes a test, in this order)
1. Given `"AQID"` / `"AQI"`, when decoded, then base64 → `[1,2,3]` / base64url → `[1,2]`; given each rejection
   case above, then `EncodingError`.
2. Given `[0xc3,0x28]`, `[0xc0,0x80]`, `[0xed,0xa0,0x80]`, when `utf8DecodeStrict`, then `EncodingError`;
   `hexEncode([0,255])` = `"00ff"`.
3. Given `JSON.parse('{"__proto__":{"a":1}}')`, `getPath(o, ["__proto__","a"])` = 1; `getPath({}, ["toString"])`
   = `undefined`; `isJsonObject(null)` and `isJsonObject([])` = false.
4. Given `new AttestationError("EXPIRED","time")`, message = `"time: EXPIRED"`; `TrustProfileError` likewise.
5. Given a branded profile, it is frozen at every depth and `isBrandedTrustProfile` is true; a structurally
   identical plain object is false. `createVerifiedAttestation` returns a frozen object.
6. Given each stub, when called, it throws `NOT_IMPLEMENTED: <owner>`; `index.ts` exports exactly the API.md
   §D public names and none of `brandTrustProfile`, `isBrandedTrustProfile`, `createVerifiedAttestation`.
7. Given ESLint `lintText` at path `packages/teecustody-core/src/attestation/x.ts` on `fetch("u")`,
   `import "cbor-x"`, `new Function("")`, `import(name)`, `import "node:fs"`, then each yields an error.
8. Given a clean clone, the four `pnpm -r` commands above exit 0 for `@teecustody/core`; `tests` package
   lint and typecheck pass (its tests are expected-red, WAVES.md).
