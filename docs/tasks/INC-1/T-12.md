## Interface contract
API.md §D (implements): `checkAudience(t, p)`, `checkTime(t, p, nowMs)`, `checkNonce(t, e)`,
`checkPlatform(t, p)`, `isDebugMode(t)`, `checkSupportAttributes(t)`. Consumes `json.ts` (`getPath`),
`encoding.ts` (`hexEncode`), `AttestationError` — all final in Wave 0; do not import T-10's `nonce.ts`
(same wave). Facts: FACTS F-05, F-08, F-14, F-15.
Spec §6 (verbatim):
- "3. **Audience.** `aud` equals `AUDIENCE`."
- "4. **Time.** `exp` is in the future and `iat` is within `TOKEN_MAX_AGE` of the client's clock."
- "5. **Nonce.** `eat_nonce` contains exactly `H(IK_pub)` in the agreed encoding."
- "6. **Platform.** `hwmodel` is in `ALLOWED_HWMODELS`; `swname` equals `CONFIDENTIAL_SPACE`; `secboot` is true;
  `dbgstat` equals `disabled-since-boot`. Debug-mode tokens MUST be rejected in every build. Development without a
  real TEE is done with the simulator (§15), whose tokens carry production-shaped values here but are trusted only
  through the development profile."
- "7. **Support attributes.** `submods.confidential_space.support_attributes` contains `STABLE`."

Rules (fixed). Absent claim → `CLAIM_MISSING`; present with wrong type or value → `CLAIM_MISMATCH`, unless stated.
- `checkAudience` ("audience"): `aud` must be a string `=== p.expected_audience` (an array is a mismatch).
- `checkTime` ("time"), in order: `exp` absent → `CLAIM_MISSING`; not a non-negative safe integer →
  `CLAIM_MISMATCH`; `exp * 1000 <= nowMs` → `EXPIRED`. `iat` same type rules; `nowMs - iat * 1000 >
  p.token_max_age_s * 1000` → `EXPIRED`; `iat * 1000 - nowMs > p.token_max_age_s * 1000` → `NOT_YET_VALID`.
  `nbf` optional; if present, same type rules and `nbf * 1000 > nowMs` → `NOT_YET_VALID`.
- `checkNonce` ("nonce"): `e.identityNonce.length !== 32` → `MALFORMED`; expected = `hexEncode(e.identityNonce)`
  (API.md §A); `eat_nonce` is a string `=== expected`, or an array of exactly one string `=== expected` (F-05);
  anything else `CLAIM_MISMATCH`.
- `checkPlatform` ("platform"), in order: `hwmodel` ∈ `p.allowed_hwmodels`; `swname === "CONFIDENTIAL_SPACE"`;
  `secboot === true`; `dbgstat === "disabled-since-boot"`.
- `isDebugMode`: `true` iff `dbgstat` is present and is not the string `"disabled-since-boot"`; never throws.
- `checkSupportAttributes` ("support_attributes"): path `submods` → `confidential_space` →
  `support_attributes` absent at any level → `CLAIM_MISSING`; not an array of strings, or lacks `"STABLE"` →
  `CLAIM_MISMATCH`.

## Acceptance criteria (each becomes a test, in this order)
1. Given `aud` equal / absent / different / `["x"]`, `checkAudience` passes / `CLAIM_MISSING` / `CLAIM_MISMATCH` ×2.
2. Given `now`, `max_age = 3600`: `exp = now/1000 + 1` passes and `exp = now/1000` → `EXPIRED`;
   `iat = now/1000 - 3600` passes and `- 3601` → `EXPIRED`; `iat = now/1000 + 3600` passes and `+ 3601` →
   `NOT_YET_VALID`; `nbf = now/1000` passes and `+ 1` → `NOT_YET_VALID`; absent `exp`/`iat` → `CLAIM_MISSING`;
   `exp: "1"`, `1.5`, `-1`, `true` → `CLAIM_MISMATCH`.
3. Given `eat_nonce` = expected string, `[expected]`, `[expected, expected]`, uppercase hex, absent, `42`,
   `checkNonce` passes ×2 / `CLAIM_MISMATCH` ×2 / `CLAIM_MISSING` / `CLAIM_MISMATCH`; a 31-byte
   `identityNonce` → `MALFORMED`.
4. Given each platform field wrong or absent in turn (`hwmodel` not listed, `swname: "GCE"`, `secboot: false`,
   `secboot: "true"`, `dbgstat: "enabled"`), the stated code; all correct passes.
5. Given `dbgstat` `"enabled"` / `"disabled-since-boot"` / absent / `42`, `isDebugMode` → true / false / false / true.
6. Given `support_attributes` `["LATEST","STABLE","USABLE"]` / `["LATEST","USABLE"]` / absent `submods` /
   `"STABLE"` (string), pass / `CLAIM_MISMATCH` / `CLAIM_MISSING` / `CLAIM_MISMATCH`.
7. Given a claims object whose prototype has `aud` (e.g. `Object.create({aud: …})`), `checkAudience` →
   `CLAIM_MISSING` (own properties only).
8. Every error message is exactly `<check>: <code>`.
9. FACTS F-05, F-08, F-14, F-15 re-confirmed; URL + access date in the Task Report.
