## Goal
Every push and pull request runs the configured test, lint and coverage commands plus the configured scanners
without cloud credentials, and fails on any forbidden, unapproved or unpinned dependency and on the INC-1
static-policy violations (default token file, listeners in the workload, TLS overrides, simulator anchors or
verification-skip identifiers in shipped code).

## Owned files
- `.github/workflows/ci.yml` (create)
- `.semgrep.yml` (create), `.semgrep/tests/*` (create: one positive and one negative fixture per rule)
- `tools/dependency_policy.py` (create)
- `tests/tooling/test_dependency_policy.py`, `tests/tooling/fixtures/**` (create)

Touching any other file is out of scope — return CONTRACT_ISSUE instead.

## Interface contract
framework.yaml (verbatim): `test_command`, `lint_command`, `coverage_command` as written there; "scanners:
[bandit, pip-audit, gitleaks, semgrep, pnpm-audit, trivy]   # trivy on the workload image; gitleaks on every PR";
dependency_policy: "OSI licences only; no package without a release in the last 18 months. Cryptographic
dependencies are limited to: cryptography, pyhpke (or Tink), cbor2, a libsodium binding for Ristretto255,
@hpke/core, cbor-x. Every crypto dependency is pinned by exact version and hash."; `forbidden_dependencies` list.

CI (fixed): GitHub Actions; triggers `push`, `pull_request`; `permissions: contents: read`; no secrets; every
third-party action pinned by full commit SHA with the version in a comment; Python 3.12 via `astral-sh/setup-uv`,
Node 22 + pnpm via `actions/setup-node` and `pnpm/action-setup`. Jobs: `test` (`pnpm install
--frozen-lockfile`, then `test_command`, then `uv run pytest -q tests` — see WAVES.md R-6), `lint`
(`lint_command`, then `uvx semgrep==<pin> --config .semgrep.yml --error --metrics=off` and `uvx semgrep==<pin>
--test .semgrep/`), `coverage` (`coverage_command`), `security` (gitleaks action on full history;
`uvx pip-audit==<pin>`; `pnpm audit --audit-level high`; `uvx bandit==<pin> -r packages/teecustody-py/src
packages/teecustody-sim/src`; `uvx semgrep==<pin> --config .semgrep.yml --error`; `uvx semgrep==<pin> --test
.semgrep/`), `deps` (`uv run python tools/dependency_policy.py`), and a `fuzz` job triggered by `schedule`
(nightly cron) and `workflow_dispatch` only, running `pnpm --filter @teecustody/core exec vitest run
test/wire/cbor-fuzz.test.ts` with `TEECUSTODY_CBOR_FUZZ_CASES=100000` (SR-3 / ADR 0010 condition; the test file
is T-09's). Trivy is deferred to INC-5 (no workload
image exists in INC-1); state this in a comment.

`.semgrep.yml` rules (ids fixed): `tc-no-default-token-file` (string `attestation_verifier_claims_token` in
`packages/teecustody-py/src/**`); `tc-no-listener-in-workload` (`$X.bind(...)`, `$X.listen(...)`,
`asyncio.start_server(...)`, `asyncio.start_unix_server(...)` in `packages/teecustody-py/src/**`);
`tc-no-tls-override` (Python `verify=False`, `ssl._create_unverified_context`, `ssl.CERT_NONE`; TS
`rejectUnauthorized: false`, `NODE_TLS_REJECT_UNAUTHORIZED`) in `packages/**`; `tc-no-sim-anchor-in-core`
(strings `tee-sim.localhost`, `SIMULATED` in `packages/teecustody-core/src/**`);
`tc-no-verification-skip` (identifier regex `(?i)(skip|disable|bypass|no)_?verif|insecure` in
`packages/teecustody-core/src/**` and `packages/teecustody-py/src/**`); `tc-no-sim-import-in-library`
(`teecustody_sim` or `teecustody-sim` referenced from `packages/teecustody-py/**` or `packages/teecustody-core/**`).
Added 2026-10-01 (numbered 7–15; "Py src" = `packages/teecustody-py/src/**`, "Sim src" =
`packages/teecustody-sim/src/**`, "Core src" = `packages/teecustody-core/src/**`):
7. `tc-py-no-dynamic-import` (Py src, Sim src): `importlib.import_module(...)`, `importlib.__import__(...)`,
   `__import__(...)`, `importlib.util.spec_from_file_location(...)`, any `runpy.$F(...)`, including when
   `importlib` / `runpy` is imported under an alias or via `from … import`.
8. `tc-py-banned-import` (every form: `import M`, `import M.N`, `import M as A`, `from M import N`,
   `from M.N import X`): in Py src `cbor2` (except `packages/teecustody-py/src/teecustody/wire/cbor.py`),
   `teecustody_sim`, `http.server`, `socketserver`, `wsgiref`, `xmlrpc.server`, `multiprocessing.connection`,
   `multiprocessing.managers`; in Sim src `cbor2`.
9. `tc-no-listener-in-workload` gains `socket.create_server(...)`, `$LOOP.create_server(...)`,
   `$LOOP.create_unix_server(...)`, `multiprocessing.connection.Listener(...)`.
10. `tc-py-no-lint-suppression` (Py src, Sim src; `pattern-regex`): a blanket `# noqa` (no `:` codes), any
    `# noqa:` list containing a `TID` code, and file-level `# ruff: noqa`.
11. `tc-ts-no-global-object` (Core src): any reference to `globalThis`, `self`, `global`, `window`, and any
    `Reflect.$M(...)` call.
12. `tc-ts-no-function-constructor` (Core src): `Function(...)`, `new Function(...)`, any binding whose
    initialiser is the identifier `Function`, `eval` referenced as a value, and **any** `constructor` member
    access in an expression (`$X.constructor`, `$X?.constructor`, `$X["constructor"]`) or the string literal
    `"constructor"` / `'constructor'` / `` `constructor` `` anywhere; class `constructor(...)` declarations and
    `.d.ts` member signatures are not expressions and stay legal.
13. `tc-ts-no-dynamic-import` (Core src): every `import(...)` expression and `require(...)` call, literal
    argument or not (so `data:`, `blob:`, `http(s):` and `node:` specifiers are all covered); plus
    `tc-ts-no-lint-suppression` (Core src, `pattern-regex`): `eslint-disable`, `@ts-ignore`, `@ts-nocheck`,
    `@ts-expect-error`.
14. `tc-ts-no-ambient-globals` (Core src; allow-list): every triple-slash directive (`pattern-regex`
    `^\s*///\s*<reference`) is forbidden; `declare global`, `declare module`, `declare namespace` are forbidden;
    any other `declare var|let|const|function|class|enum` is forbidden **except** (i) in
    `packages/teecustody-core/src/platform.d.ts`, where only `declare class TextEncoder`, `TextDecoder`, `URL`
    are allowed (metavariable-regex on the name), and (ii) `declare const $N: unique symbol` (brand symbols,
    e.g. `attestation/types.ts`). Positive fixture: `declare class EventSource {…}; new EventSource(url)`.
15. `tc-ts-no-timers` (Core src): any reference to `setTimeout`, `setInterval`, `setImmediate`,
    `queueMicrotask`, `execScript` (Core has no timers in INC-1; an INC-2 need comes via an injected port).

`tools/dependency_policy.py` (stdlib only; `tomllib`, `json`, `urllib`): `main(argv) -> int`; options
`--root PATH` (default repo root), `--offline`, `--today YYYY-MM-DD` (default today). Reads `uv.lock`,
`pnpm-lock.yaml` (line-based parse of package keys, versions and `integrity`), every `pyproject.toml` and
`package.json` under `packages/`. Prints one line per violation, `VIOLATION <rule> <package>`, exits 1 if any,
else 0. Rules: `forbidden` (any `forbidden_dependencies` name in either lock); `crypto-unapproved` (any lock
package in the constant `KNOWN_CRYPTO` set — at least `pycryptodome, pycryptodomex, pynacl, pyjwt, python-jose,
jwcrypto, authlib, ecdsa, rsa, tinyec, pyaes, pycrypto, jose, jsonwebtoken, tweetnacl, node-forge, elliptic,
crypto-js, sjcl` plus any name starting `@noble/` — that is not in `APPROVED_CRYPTO` = `cryptography, pyhpke,
tink, cbor2, @hpke/core, cbor-x`); `crypto-unpinned` (an approved crypto package that is not `==`/exact in its
manifest or lacks a lock hash/integrity); `sim-in-library` (`teecustody-sim` in the dependency closure of
`teecustody` in `uv.lock`, or in any `packages/*/package.json`); `core-runtime-deps` (`@teecustody/core`
`dependencies` ⊄ {`@hpke/core`}; ADR 0010: no package uses `cbor-x`); `cbor-x-unused` (`cbor-x` in any
`packages/*/package.json` or in `pnpm-lock.yaml`); unless `--offline`: `licence` (PyPI JSON / npm registry licence
not in SPDX set `MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0, ISC, MPL-2.0, PSF-2.0, Python-2.0, 0BSD,
Unlicense`) and `stale` (latest release older than 18 months before `--today`) for every direct dependency.
Network access goes through one injectable function so tests use recorded fixtures.

## Acceptance criteria (each becomes a test, in this order)
1. Given a fixture repo tree with no violation, `main(["--root", fx, "--offline"])` returns 0 and prints nothing.
2. Given one fixture per rule (`forbidden`, `crypto-unapproved`, `crypto-unpinned` ×2 — range spec and missing
   hash, `sim-in-library`, `core-runtime-deps`, `cbor-x-unused`, `licence`, `stale`), `main` returns 1 and prints exactly that
   rule's line (SR-9 test description).
3. Given the real repo, `main(["--offline"])` returns 0.
4. Given `framework.yaml`, every `forbidden_dependencies` package name appears in the tool's forbidden set
   (text match of the YAML list items).
5. Given `.semgrep/tests`, `semgrep --test` passes (run in CI; record the local run output in the Task Report).
6. Given `.github/workflows/ci.yml`, `actionlint` reports no error, every job above is present, and the `fuzz`
   job has no `push`/`pull_request` trigger (record the local output in the Task Report).
7. Given `.semgrep/tests`, each rule 7–15 has a negative fixture and positive fixtures (`ruleid:` annotations)
   for at least these bypasses: `importlib.import_module("http.server")`, `__import__("cbor2")`,
   `from importlib import import_module as im; im("socketserver")`, `import cbor2  # noqa: TID251`,
   `# ruff: noqa`, `import wsgiref.simple_server`, `from xmlrpc.server import SimpleXMLRPCServer`,
   `multiprocessing.connection.Listener(("0.0.0.0", 1))`, `asyncio.start_server(h, port=1)`,
   `(globalThis as unknown as { fetch: F }).fetch("u")`, `Reflect.get(globalThis, "localStorage")`,
   `const F = Function; new F("")`, `(() => 0).constructor("")`, `const C = [].constructor.constructor`,
   `x["constructor"]`, `import("data:text/javascript,0")`, `// @ts-expect-error` followed by
   `import("node:fs")` and by `import("cbor-x")`, `declare const fetch: F`, `declare class EventSource {}`,
   `/// <reference lib="dom" />`, `/// <reference types="node" />`, `declare function setTimeout(c: string,
   t: number): number; setTimeout("code", 0)`; negative fixtures include a class with a `constructor(...)`,
   `declare const brand: unique symbol`, and a copy of T-02's `platform.d.ts`; `semgrep --test .semgrep/` passes and
   `semgrep --config .semgrep.yml --error` over the repo reports nothing on trunk (record both outputs).

## Security requirements
- SR-9: criteria 1–4. SR-5: `tc-no-tls-override`. NFR-5/I13: `tc-no-verification-skip`.
- NFR-6: `sim-in-library`, `core-runtime-deps`, `tc-no-sim-import-in-library`. §13.10 early: `tc-no-sim-anchor-in-core`.
- NFR-2 / NFR-6 / SR-3 (bypass resistance): criterion 7 — every ban holds against dynamic import, global-object
  access, constructor aliasing and suppression comments; semgrep ignores `noqa` / `eslint-disable` by design.

- Do not edit `packages/*/ruff.toml` or `eslint.config.js` (T-01/T-02 files). If a new rule fires on existing trunk code, stop: CONTRACT_ISSUE (do not weaken the rule).
