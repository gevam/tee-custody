# D-05 Gateway slow-read DoS: a pipelining client that never reads holds concurrency slots forever

- Severity: **Medium** (SR-4, THREAT_MODEL T-07). Pre-existing; stock uvicorn 0.54.0 behaves the same.
- Component: `examples/notes-app/gateway` (server protocol; T-40's `notes_gateway/server.py` is the natural place).
- Found by: Security Reviewer, T-40 review (2026-10-15), live test against c061403.

## Reproduction (reviewer)
A client pipelines requests and never reads the responses. The transport's write buffer fills, and the app's send awaits drain indefinitely. The per-source in-flight slots are never released, so every other request from that source gets 429. With enough sources, the global capacity is held too.

## Expected
A write/drain deadline: if the peer does not drain a pending response within a bounded time, the connection is closed and its slots are released. Fix route: T-40 amendment (Tech Lead).
