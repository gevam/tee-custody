# D-06 Gateway keeps the connection open for a request with both Content-Length and Transfer-Encoding

- Severity: **Low**. Pre-existing; RFC 9112 §6.3 says such a message is treated as an error, or the connection is closed after the response.
- Component: `examples/notes-app/gateway` server protocol.
- Found by: Security Reviewer, T-40 review (2026-10-15).

## Reproduction (reviewer)
A request carrying both `Content-Length` and `Transfer-Encoding: chunked` is answered, and the connection stays keep-alive. No desync was observed, because h11 uses chunked framing, but RFC 9112 requires closing the connection.

## Expected
The connection closes after the response; or the request is rejected with the JSON 400 per INC-2-API §6. Fix route: T-40 amendment (Tech Lead).

## Status: OPEN
