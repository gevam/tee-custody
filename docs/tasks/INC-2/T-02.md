## Interface contract
Transcribe exactly: INC-2-API §7.1–§7.5 and §8.1–§8.5 (public), API-TL §3 (internal), API-TL §4 (exports).
A-2 body change: `createVerifiedAttestation` adds its frozen result to a module `WeakSet`; new internal
`export function isVerifiedAttestation(v: unknown): v is VerifiedAttestation`. `createVerifiedBundle` (A2,
INC-2-API §7.2 verbatim):
- copies `identityPublicKey` and each `prekeys[i].publicKey` into a module-private `WeakMap` entry keyed by the
  new frozen object;
- defines those fields with `Object.defineProperty(obj, name, { get: () => stored.slice(), enumerable: true })`,
  with no setter, before `Object.freeze` (bundle, `prekeys` array and every entry);
- registers the object in the `WeakSet`.

The input buffers are never retained. `DEFAULT_CHANNEL_LIMITS`
values are INC-2-API §7.4's comments, `Object.freeze`d (nested limits too). `systemClock`:
`{ now: () => Date.now(), sleep: (ms) => new Promise((r) => setTimeout(r, ms)) }`. In `session.ts`
declare `export type SessionInit = Readonly<Record<string, never>>` as a placeholder (T-26 replaces it,
API-TL §3) and `Session`'s constructor `constructor(token: symbol, init: SessionInit)`.

Web package (fixed): name `@teecustody/web`, `type: module`, `exports` `./dist/index.js`, `engines.node >=22`,
`dependencies: {"@teecustody/core": "workspace:*"}`; devDependencies exact: `@playwright/test`,
`fake-indexeddb`. Scripts: `test` `vitest run`, `coverage` `vitest run --coverage`, `lint`
`eslint . && prettier --check .`, `typecheck` `tsc --noEmit -p tsconfig.json && tsc --noEmit -p

## Acceptance criteria (each becomes a test, in this order)
1. Given `@teecustody/core`, then `Object.keys(core)` equals INC-1 values + API-TL §4 values, and
   `isVerifiedAttestation`, `isVerifiedBundle`, `createVerifiedBundle`, `openT2cFrame`, `readOpenResult`,
   `readFrameResult`, `decodeResponse`, `hpkeInfo` are absent.
2. Given `@teecustody/web`, then `Object.keys(web)` equals the API-TL §4 web values; `expectTypeOf` pins every
   §8 signature.
3. Given `createVerifiedAttestation(f)`, then `isVerifiedAttestation` is true for it and false for
   `{...it}`, for `Object.freeze({...it})` and for `null`.
4. Given `createVerifiedBundle(f)`, then `isVerifiedBundle` is true and a structural copy is false. Then
   INC-2-API §7.2 tests (1)–(5), each mutating what the API returned:
   - (1) `b.identityPublicKey.set(0xee…)`, then a fresh read returns the original bytes, and `isVerifiedBundle(b)`
     is still true.
   - (2) The same for `b.prekeys[i].publicKey`.
   - (3) Two reads return distinct objects with equal bytes.
   - (4) Mutating `f`'s buffers after the call has no effect.
   - (5) In strict mode, assigning a field or `Object.defineProperty` on a field throws. `Object.isFrozen` holds
     for the bundle, `prekeys` and every entry. The getters have no setter
     (`Object.getOwnPropertyDescriptor(...).set === undefined`).
5. Given `DEFAULT_CHANNEL_LIMITS`, then each value equals §7.4 and `Object.isFrozen` holds at every level.
6. Given `testChannelCrypto()`, then a fake-HPKE seal opens with the matching receiver, exports agree on both
   sides, a wrong `info` fails, and `aeadSpy` records one entry per `aes256GcmEncrypt`.
7. Given `systemClock.sleep(5)`, then it resolves after ≥ 5 ms.
8. Given a web src file containing `{ ekm: x }` or `import "@hpke/core"` outside `crypto/webcrypto.ts`,
   then `eslint` reports an error (lint-policy test using ESLint's Node API on inline text).
   - A2(b): each of `{"ekm": k}`, `{"psk": 1}`, `{["psk"]: 1}`, `o["senderKey"] = k`, `f(opts.psk)` and
     `const { senderPublicKey } = o` reports a C5 error in a Core src file and in a Web src file.
   - `{ pskIdentity: 1, info: 2 }` reports none.
   - The C5 list becomes exactly these five selectors, each with the C5 message, with
     `N = (ekm|psk|pskId|senderKey|senderPublicKey)`:
     - `Property[key.name=/^N$/]`
     - `Property[key.value=/^N$/]`
     - `MemberExpression[property.name=/^N$/]`
     - `MemberExpression[property.value=/^N$/]`
     - `Identifier[name=/^N$/]`

     The Tech Lead verified them with ESLint's `Linter` on these cases. A template-literal key such as
     ``{[`psk`]: 1}`` is caught by semgrep `tc-ts-no-hpke-seams`, not by ESLint.
9. Given a clean clone, then the four pnpm commands above exit 0 (expected-red tests excepted).
10. A2(c), GHSA-68fv-2mgg-jv7q.
    - `pnpm-workspace.yaml` gains a top-level `overrides:` map with exactly `"source-map-js@<1.2.2": "1.2.2"`.
    - Regenerate `pnpm-lock.yaml`. `source-map-js` then appears only at 1.2.2, through
      `@vitest/coverage-v8` → `magicast` and `vite` → `postcss`.
    - Given `pnpm audit --audit-level high`, then it exits 0.
    - Given `grep -c "source-map-js@1.2.1" pnpm-lock.yaml`, then it prints 0.
    - Record both outputs in the Task Report. The audit needs network, so it is a recorded check, and the CI
      `deps` job's `pnpm audit` enforces it.
    - Use the override, not a lock-only update, so a fresh resolution cannot reintroduce 1.2.1.
