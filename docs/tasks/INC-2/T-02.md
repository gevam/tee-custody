## Acceptance criteria (each becomes a test, in this order)
1. Given `@teecustody/core`, then `Object.keys(core)` equals INC-1 values + API-TL §4 values, and
   `isVerifiedAttestation`, `isVerifiedBundle`, `createVerifiedBundle`, `openT2cFrame`, `readOpenResult`,
   `readFrameResult`, `decodeResponse`, `hpkeInfo` are absent.
2. Given `@teecustody/web`, then `Object.keys(web)` equals the API-TL §4 web values; `expectTypeOf` pins every
   §8 signature.
3. Given `createVerifiedAttestation(f)`, then `isVerifiedAttestation` is true for it and false for
   `{...it}`, for `Object.freeze({...it})` and for `null`.
4. Given `createVerifiedBundle(f)`, then `isVerifiedBundle` is true; a structural copy is false; mutating
   `f.prekeys[0].publicKey` afterwards does not change the bundle.
5. Given `DEFAULT_CHANNEL_LIMITS`, then each value equals §7.4 and `Object.isFrozen` holds at every level.
6. Given `testChannelCrypto()`, then a fake-HPKE seal opens with the matching receiver, exports agree on both
   sides, a wrong `info` fails, and `aeadSpy` records one entry per `aes256GcmEncrypt`.
7. Given `systemClock.sleep(5)`, then it resolves after ≥ 5 ms.
8. Given a web src file containing `{ ekm: x }` or `import "@hpke/core"` outside `crypto/webcrypto.ts`,
   then `eslint` reports an error (lint-policy test using ESLint's Node API on inline text).
9. Given a clean clone, then the four pnpm commands above exit 0 (expected-red tests excepted).
