## Interface contract
- `channel.cddl` = INC-2-API §3.1 code block, byte for byte (strip nothing; keep comments).
  `channel-vectors.cddl` = §3.2 code block, byte for byte.
- "Channel byte layouts" = INC-2-API §2 (table, the builder-rejection list and the error rule) verbatim.
- "Channel schema rules" states, verbatim from §3.1 "Notes for the approver" and §4.5: ascending pre-key ids
  (R-2); `ok` ⇔ non-nil `session_id` (R-3); every time field and `seq` is an integer in [0, 2^53−1] (R-1);
  unknown keys rejected; nested `.cbor` aad must re-encode to its own bytes.
- `spec/vectors/README.md` "channel/suite.cbor" format section, fixed here:
  - decode limits `CHANNEL_SUITE_LIMITS` = `max_bytes` 4 194 304, `max_depth` 8, `max_items` 65 536;
  - `verify_at_ms` is "now" for every bundle and expiry check;
  - `bundle-case.instance_id` is the published instance id (`PublishedBundle.instanceId`);
  - open/frame `plaintext` (and open `sk_c2t`/`sk_t2c`) are non-nil iff `expect == "accept"`;
  - `result-case.plaintext` is the decrypted canonical plaintext iff the AEAD verifies (all `accept` cases
    and every `reject`/`INVALID_RESPONSE` case), nil for `ignore`;
  - `layout-case.inputs` keys: `prekey_preimage` → `instance_id`, `prekey_id`, `pub`, `not_after`,
    `image_digest`; `hpke_info` → `ik_pub`, `prekey_id`; `session_nonce` → `seq`;
  - the named cases of INC-2-API §3.2 (listed exactly, per array); frame case ids are
    `<direction>_<name>` (e.g. `c2t_valid`, `t2c_seq_equal_last`), so every id in an array is unique;
    `seq_above_max` frames carry `error_code` `INVALID_ENVELOPE` (2^53 fails the schema before any seq check);
    layout ids are `<kind>_accept` and `<kind>_<field>_range` (e.g. `prekey_preimage_not_after_range`);
  - the per-language split API-TL TL-9.
- `test_channel_suite.py` reads `CHANNEL_SUITE_PATH`, never imports `teecustody_sim`, and checks (TL-9 Python
  column): suite keys exactly as the CDDL; `proto == PROTO`; every named case id present once; `opens` via
  `decode_request` + `open_base(Secret(recipient_private_key), env.enc, hpke_info(ik_pub, prekey_id),
  env.aad_bytes, env.ct)` (`INVALID_ENVELOPE` ↔ `EnvelopeError`, `OPEN_FAILED` ↔ `HpkeError`, exports equal
  `sk_c2t`/`sk_t2c`); `frames` with `direction == "c2t"` via `decode_request` + `open_frame(Secret(key),
  last_seq, …)` (`SEQ_REJECTED`/`AUTH_FAILED` ↔ `SessionReject` code); `results` via `decode_response` +
  `decode_open_result_plaintext` on `plaintext` (`INVALID_RESPONSE` ↔ `EnvelopeError(INVALID)`); `layouts` via
  `hashlib.sha256(bytes).digest() == prekey_signing_message(**inputs)`, `hpke_info(...) == bytes`,
  `teecustody.channel.session._nonce(seq) == bytes`, rejects ↔ `ValueError`; `bundles`: cases with
  `error_code == "MALFORMED"` raise `EnvelopeError` from `decode_bundle(bundle, DecodeLimits(65536, 4, 4096))`,
  all other cases decode. Plus a bounded mutation fuzz (seed 1, 2 000 mutations of every request/response
  envelope in the suite): `decode_request`/`decode_response` only return or raise `EnvelopeError`, each
  < 50 ms.
