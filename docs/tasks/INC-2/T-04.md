## Interface contract
Transcribe exactly — names, parameter names/order, keyword-only markers, defaults, return types, enum
members and values, constants, dataclass options (`frozen`, `slots`, `kw_only`, `eq=False`, `repr=False`
fields) and field order — from INC-2-API §4.1–§4.13, §5.1, and API-TL §2. Stub bodies raise
`NotImplementedError("<owner>")` with the owner from API-TL §1. `config.py` dataclasses carry no
`__post_init__` (T-09 adds it). `hpke.py` does not import `pyhpke` (T-08 adds it). `AggregateOutcome` has
exactly the 12 §10 codes, in table order, value = name. Every exception class stores only its code;
`str(err) == err.code.value` (`ConfigError`: `f"{code}:{field}"`).

`Secret` (§4.1, implemented): copies input into a private `bytearray`; `INVALID_LENGTH` for length 0 or
> 65536 (`random`: length outside 1..65536); `reveal()` returns `bytes(self._buf)`; `equals` uses
`hmac.compare_digest`; `wipe()` overwrites every byte with 0 then clears; `__repr__`/`__str__`/`__format__`
return `"Secret(<redacted>)"`; `__eq__`, `__bytes__`, `__reduce__`, `__reduce_ex__`, `__iter__`,
`__getitem__` raise `SecretError(FORBIDDEN)`; `__hash__ = None`; context manager wipes.

`IdentityKey.sign(message: bytes) -> bytes` (§4.2, implemented): `ValueError("MESSAGE_LENGTH")` unless
`len(message) == 32`; otherwise Ed25519 PureEdDSA signature (64 bytes) from `cryptography`.

## Acceptance criteria (each becomes a test, in this order)
1. Given `test_api_surface_inc2.py`, then every API-TL §4 name imports from its package root, and
   `inspect.signature(..., eval_str=True)` of every public function/method equals a spec stub written in the
   test (INC-1 `FROZEN_SIGNATURES` pattern).
2. Given each enum, constant and dataclass, then members/values/defaults/field order equal INC-2-API literals
   written in the test; every `*_PATTERN` has no `^`/`$` and `fullmatch` rejects a valid value + `"\n"`.
3. Given `Secret(b"k" * 32)`, then `repr`, `str`, `f"{s}"` are `"Secret(<redacted>)"`; `pickle.dumps`, `bytes(s)`,
   `s == s`, `iter(s)`, `s[0]`, `hash(s)` fail as specified; `len`, `reveal`, `equals` behave per §4.1.
4. Given a `Secret` whose buffer is captured via a test-only reference, when `wipe()`, then every byte is 0
   before the buffer is emptied, `wiped` is true, `reveal`/`equals` raise `WIPED`, `wipe()` again is a no-op.
5. Given lengths 0, 65537 and `random(0)`, then `INVALID_LENGTH`; `Secret.random(32)` twice differ.
6. Given `IdentityKey`, when `sign(b"x" * 32)`, then `cryptography` verifies it under `public_bytes()`;
   `sign(b"x" * 31)` and 33 bytes raise `ValueError("MESSAGE_LENGTH")`.
7. Given `importlib.import_module("teecustody.channel")`, then no module in `teecustody` imports
   `teecustody_sim` or `tests` (scan `sys.modules` after import).
8. Given the full Python suite, then INC-1 tests stay green (the modified root-exports test included).
