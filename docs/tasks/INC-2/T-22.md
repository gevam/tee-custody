## Goal
The workload holds a bounded pool of single-use X25519 pre-keys, each signed once by the identity key over
the attested image digest, hands each private key out at most once, and publishes them in a canonical bundle.

## Interface contract
INC-2-API §4.7 verbatim:
```python
class PreKeyStore:
    def __init__(self, *, instance_id: str, identity: IdentityKey, image_digest: str,
                 params: ChannelParams, clock: Callable[[], float]) -> None: ...
    def top_up(self) -> int: ...          # if live count < low_water (or 0): generate up to `batch` live keys; returns number generated
    def expire(self) -> int: ...          # destroys keys with not_after <= now; returns count
    def public_entries(self) -> tuple[PreKeyPublic, ...]: ...   # live, unexpired, sorted by id
    def take(self, prekey_id: int) -> Secret: ...   # removes and returns the private key; KeyError("PREKEY_UNKNOWN") if unknown/consumed/expired
    def consumed_since(self, since: float) -> int: ...   # for PREKEY_BURN_HIGH
    def destroy_all(self) -> None: ...
    # ids are allocated from a per-instance counter starting at 0; uint32 exhaustion → RuntimeError("PREKEY_IDS_EXHAUSTED") (instance restarts)
def build_bundle(*, instance_id: str, token: AttestationToken, ik_pub: bytes,
                 prekeys: Sequence[PreKeyPublic], published_at: int) -> bytes: ...   # canonical prekey-bundle
```
> `not_after = floor(now) + prekey_ttl_s`; `sig` is computed once at generation (it does not cover the token).
> `IdentityKey.sign` is called only from `channel/prekeys.py`.

Decisions: "live" = not taken and `not_after > now`. `top_up` generates `batch − live` keys when
`live < low_water` or `live == 0`, else 0; keys come from `hpke.generate_keypair()`; `sig =
identity.sign(prekey_signing_message(instance_id, id, pub, not_after, image_digest))`. `take` on an expired
key wipes it and raises `KeyError("PREKEY_UNKNOWN")`. `expire` and `destroy_all` call `Secret.wipe()` on every
destroyed private key. `consumed_since(t)` counts successful `take` calls at clock times ≥ `t` (timestamps kept
in a deque trimmed to the last 2 × 3600 s). The constructor validates `instance_id` (32 lowercase hex,
`fullmatch`) and `image_digest` (`IMAGE_DIGEST_PATTERN.fullmatch`) → `ValueError("<FIELD>_RANGE")`.
`build_bundle` encodes via `codec.encode_bundle` (ids ascending; 1..256 entries, else `ValueError`).

## Acceptance criteria (each becomes a test, in this order; fake clock)
1. Given an empty store, when `top_up`, then `batch` keys exist with ids 0..batch−1, `not_after = floor(now) +
   ttl`, and each `sig` verifies (Ed25519, `cryptography`) over `prekey_signing_message(...)` with the store's
   digest under `identity.public_bytes()`.
2. Given `live ≥ low_water`, then `top_up` returns 0; after taking keys below `low_water`, it refills to `batch`.
3. Given `take(id)`, then a 32-byte `Secret` whose X25519 public key equals the entry's `pub`; a second
   `take(id)`, an unknown id, and an expired id raise `KeyError("PREKEY_UNKNOWN")`.
4. Given the clock past `not_after`, then `expire` returns the count, those keys are wiped (captured `Secret`s
   report `wiped`) and absent from `public_entries`.
5. Given 7 takes at known times, then `consumed_since(t)` counts exactly those at or after `t`.
6. Given the id counter at 2^32 − 1 used, then the next generation raises `RuntimeError("PREKEY_IDS_EXHAUSTED")`.
7. Given `destroy_all`, then every private key is wiped and `public_entries()` is empty.
8. Given `build_bundle`, then `codec.decode_bundle` returns the same instance id, token value, IK, entries in
   id order and `published_at`; 0 or 257 entries raise `ValueError`.
9. Given a bad `instance_id` (uppercase, `"\n"` suffix) or digest, then the constructor raises.
10. Given `IdentityKey.sign` patched to record calls, then it is called once per generated key and never by
    `build_bundle`.
