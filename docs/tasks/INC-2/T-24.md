## Interface contract
INC-2-API §4.11 (Queue port, errors, delivery rules) and §5.1 verbatim:
```python
class InMemoryQueue:                       # implements teecustody.queue.ports.Queue; thread-safe
    def __init__(self, *, namespace: str = "sim", ack_deadline_s: float = 30.0,
                 request_retention_s: float = 300.0, response_retention_s: float = 300.0,
                 max_topic_depth: int = 10_000, max_bundles: int = 64,
                 clock: Callable[[], float] = time.time, rng: Callable[[int], bytes] = os.urandom) -> None: ...
class InMemoryAuditSink:                   # implements AuditSink; thread-safe
    def __init__(self) -> None: ...
    def append(self, key: AuditKey, record: AuditRecord) -> AppendResult: ...  # validate_audit first; ALREADY_EXISTS if key present
    def records(self, record_class: AuditClass | None = None) -> list[tuple[AuditKey, AuditRecord]]: ...  # test inspection, insertion order
    def fail_next(self, n: int, code: AuditErrorCode = AuditErrorCode.UNAVAILABLE) -> None: ...  # fault injection
```
> `pull_requests` blocks up to `wait_s` on a condition variable; un-acked messages become visible again after
> `ack_deadline_s`; requests older than `request_retention_s` and responses older than `response_retention_s` are
> dropped; response cursors are the decimal per-client sequence number of the last returned response (`after`
> not decimal or greater than the last issued → `INVALID_ARGUMENT`); a full topic → `UNAVAILABLE`; `namespace`
> must match `^[a-z][a-z0-9-]{0,31}$`.

Decisions: write the namespace pattern without anchors and check it with `fullmatch` (R-7; `ValueError
("NAMESPACE")` at construction). Message ids are `rng(16).hex()`. Every id argument is checked with
`fullmatch` against `INSTANCE_ID_PATTERN`/`CLIENT_ID_PATTERN`/`RELAY_ID_PATTERN`; `max_messages`/`max_bundles`
must be ints 1..1000, `wait_s` 0 ≤ x ≤ 30; violations → `QueueError(INVALID_ARGUMENT)`. `publish_bundle` with
`expires_at <= now`, or a 65th distinct instance when `max_bundles` are live → `INVALID_ARGUMENT` /
`UNAVAILABLE`. `pull_responses` returns responses with sequence > `after` (or all), oldest first, up to
`max_messages`; `next` = decimal sequence of the last returned, or `None` if nothing was returned. Retention
purges run on every call. `fail_next(n, code)` makes the next `n` `append` calls raise `AuditError(code)`
before storing. `records` returns copies; the sink never overwrites. Never log bodies.

## Acceptance criteria (each becomes a test, in this order; fake clock)
1. Given `publish_bundle(i, b, expires_at)`, then `list_bundles` returns it until `expires_at`, sorted by
   instance id; republishing replaces; `withdraw_bundle` removes and is idempotent.
2. Given no live bundle for `i`, then `publish_request(i, …)` → `NOT_FOUND`.
3. Given a published request, then `pull_requests` returns it with `message_id`, relay `request_id`, body and
   `published_at`; un-acked it reappears after `ack_deadline_s`; after `ack` it never reappears; `ack` of an
   unknown id is a no-op.
4. Given an empty topic and `wait_s = 0.2`, then `pull_requests` returns `[]` after ≈ 0.2 s; a publish from
   another thread wakes it early.
5. Given 5 responses for client c, then pages of 2 with `after` cursors return them in order with correct
   `next`; `after` = `"x"`, `"-1"` or beyond the last issued → `INVALID_ARGUMENT`; another client's route
   returns an empty page.
6. Given request/response retention elapsed, then they are dropped; given `max_topic_depth` reached, then the
   next publish → `UNAVAILABLE`.
7. Given every id argument with uppercase, 31/33 chars or a trailing `"\n"`, then `INVALID_ARGUMENT` (R-7).
8. Given `InMemoryAuditSink`, then a valid record → `CREATED`, the same key again → `ALREADY_EXISTS` and the
   original is kept; an invalid record (`count` on ALERT) → `AuditError(INVALID_ARGUMENT)`; `fail_next(2)` makes
   exactly two appends raise `UNAVAILABLE`.
9. Given 8 threads publishing/pulling/acking 1 000 messages, then every message is delivered at least once and
   none after its ack (thread-safety).
