## Goal
One command runs simulator, workload, in-memory queue and gateway on loopback, and a Node client using the
real web adapters opens a session, round-trips `test.echo`, and closes — the first full INC-2 vertical slice.

## Interface contract
INC-2-API §9.4 verbatim and API-TL TL-5, TL-8:
> One Python process: `Simulator` (`teecustody-sim serve` equivalent, loopback), `RunLoop` in a thread with
> `ConfidentialSpaceLauncher(socket_path=<sim socket>)`, `InMemoryQueue`, `InMemoryAuditSink`,
> `StaticShareOpener({FIXTURE_CLIENT_ID: FIXTURE_CS})`, `EchoHandler`, and the gateway under uvicorn on
> 127.0.0.1:0. It prints one stdout line `gateway=<origin> issuer=<origin> profile=<path>` once ready, and stops on
> SIGTERM. The workload component has no listener; only the gateway listens (D-003). `FIXTURE_CS` is generated per
> run and written only to the harness's temporary directory for the browser test to `vault.set`; it is never committed.

Decisions: the harness inserts the repository root into `sys.path` and imports
`tests.support.channel_doubles`; temp dir via `tempfile.mkdtemp(prefix="tc-e2e-")` (removed on exit); the
profile is `teecustody_sim.build_trust_profile(jwks_uri=simulator.jwks_uri, ...)` (v2) for the running
simulator (same `LaunchConfig`, audience `https://e2e.teecustody.test/tee`), written as `profile.json`;
`fixture.json` per TL-8 (amended) with `key_id` 16 random bytes and `epoch` 0, plus `discovery_url`
(`simulator.discovery_url`), `attacker_jwks_url` (`simulator.attacker_jwks_uri`) and `attacker_token`. The
attacker token is minted per §9.4 with `TokenMinter(simulator.keys, launch, ttl_s=…, token_max_age_s=…).mint(
audience, [<64-hex nonce>], now, NamedCase("jwks_other_path"))`. It is not a secret. Uvicorn: `uvicorn.Server(uvicorn.Config(app, host="127.0.0.1", port=0, access_log=False,
proxy_headers=False, server_header=False, log_level="warning"))`, never with `forwarded_allow_ips` (A3, INC-2-API §6
"Server configuration"; `dev.py` uses the same three settings) in a thread; the origin is read from the bound socket. `--cors-origin` values go to
`GatewayLimits(cors_origins=…)`. The ready line is printed only after the first bundle is listed by the queue.
SIGTERM/SIGINT: stop the run loop (`stop.set()`), stop uvicorn, stop the simulator, exit 0 within 10 s.
`dev.py` (TL-5): runs `create_app(InMemoryQueue())` under uvicorn on `--host`/`--port`, prints
`gateway=<origin>`, imports `teecustody_sim` inside `main` only. Node test: spawns `uv run python
tests/e2e/channel_harness.py` from the repo root, builds `ChannelClient` with `parseTrustProfile`, `FetchTransport`
(`maxResponseBytes` 1 048 576, `timeoutMs` 10 000), `createWebCrypto()`, `FetchFetcher` (`maxBodyBytes` 65 536,
`timeoutMs` 10 000), a recording `SecurityEventSink`, `systemClock`; test timeout 60 s.

## Acceptance criteria (each becomes a test, in this order)
1. (Python) Given the harness started as a subprocess, then within 30 s it prints exactly one line matching
   `^gateway=http://127\.0\.0\.1:\d+ issuer=http://127\.0\.0\.1:\d+ profile=/\S+$`; `profile.json` parses and
   `fixture.json` has mode 0600.
2. (Python) Given the ready harness, then `GET /bundles` returns one bundle whose `decode_bundle` instance id equals
   the published one.
3. (Python) Given SIGTERM, then exit code 0 within 10 s and the temp dir is gone.
4. (Node) Given the harness, when `open({op:"open_session", clientId, cs, keyId, epoch})`, `request("test.echo",
   Map{x:1})`, `close()`, then the echo equals the input, no security event was reported, and `closed` is true.
5. (Node) Given a wrong `cs`, then `ChannelError("REMOTE_ERROR")` with `detail` `"AUTHENTICATION_FAILED"`.
6. (Node, FR-5) Given a completed exchange, then polling `GET /responses/<other 32-hex route>` returns an empty
   page (responses are delivered only on the AAD route).
7. (dev) Given `python -m notes_gateway.dev --port 0`, then it prints `gateway=<origin>` and `GET /bundles` → 200
   `{"bundles":[]}`; SIGTERM exits 0. (A3) The `dev.py` test asserts that the `uvicorn.Config` it builds has `proxy_headers is False`,
   `server_header is False`, `access_log is False` and `forwarded_allow_ips` unset. A harness test asserts the
   same for the harness's `Config`.
8. (N1, Node) Given a recording Fetcher wrapping `FetchFetcher` during `ChannelClient.open`, then every recorded
   URL equals `profile.jwks_uri`.
9. (N2, Node) Given `verifyAttestation(fixture.attacker_token, …)`, then `signature` / `UNTRUSTED_SIGNER`,
   while `FetchFetcher.get(fixture.attacker_jwks_url)` → 200.
10. (N3, Node) Given `pnpm --filter @teecustody/web run build:cli` once, then
    `node packages/teecustody-web/dist/profile/bin.js check-discovery --profile <harness profile> --discovery-url
    <fixture.discovery_url> --probe-cors http://127.0.0.1:1` (TL-10) exits 0, and its single line ends with
    `jwks_acao=http://127.0.0.1:1 discovery_acao=absent` (CI-2-4 echo, amended §16.9 N3).
